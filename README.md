# HLM ERP - downloads

This repository holds only the **HLM ERP installers** published by HLM Consultants
(installer, Quick Start PDF, release notes and checksums). It contains no source code and no customer data.

- Download page: https://hlmconsultants.com/erp
- Latest installer: see **Releases** on the right.
- Check your download: the SHA-256 of `HLM ERP Setup <version>.exe` must match `SHA256.txt` in the same release
  (Windows: `certutil -hashfile "HLM ERP Setup <version>.exe" SHA256`).
- HLM ERP starts with a 14-day free trial; continued use needs a licence key from HLM Consultants.
  Use is governed by the licence agreement shown during setup.
